# AI-Tell Checklist (fallback when the humanizer skill is unavailable)

Use this to rewrite prose, and in QA to scan for leftovers. It covers the most common patterns, not every one.

| Pattern | Example | Fix |
|---|---|---|
| Not-X-but-Y contrasts | "It's not a process, it's a mindset." | State the claim directly. |
| Forced triads | "faster, smarter, and more scalable" | Keep the items that are true and specific. |
| Inflated stakes | "crucial", "game-changing", "pivotal", "revolutionise" | Plain words, or show the consequence. |
| Stock AI vocabulary | delve, tapestry, landscape, realm, robust, seamless, leverage (as a verb), navigate (figuratively), unlock, empower, elevate, foster, holistic, myriad, testament | Replace with a concrete word or cut. |
| Staged openers | "Here's the thing:", "Let's be honest:", "The truth is," | Start with the point. |
| One-line closers | "And that makes all the difference." | Delete, or end on the last substantive sentence. |
| Dash overuse | More than one em dash per paragraph | Use commas, colons, full stops or brackets. |
| Hedge stacks | "may potentially help to some extent" | One hedge, or none. |
| Bold-label bullets everywhere | "**Clarity:** …" in every list | Use them only when scanning genuinely helps. Otherwise write prose. |
| Symmetric rhythm | Every paragraph is 3 sentences of the same length | Vary length, with some short sentences. |
| Generic second person | "You might be wondering…" | Cut it, or address a specific situation. |
| Sales language | "unlock your potential", "take your career to the next level" | Remove, especially under educational-only. |
| Signposting | "In this article, we will explore…" | Replace with the answer-first definition. |
| Summary echo | "In conclusion, PLM is important because…" | End with the last useful decision rule. |

**Protected elements:** never alter them while fixing tells. See the list in sai-cc-humanize.
